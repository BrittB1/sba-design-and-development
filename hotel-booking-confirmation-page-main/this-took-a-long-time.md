# 🏨 Hotel Booking Confirmation Page
 
A responsive hotel booking confirmation page built as a solution to the
[Frontend Mentor](https://www.frontendmentor.io/challenges/hotel-booking-confirmation-page)
challenge. The page recreates a booking confirmation for *Maison Soleil*, a
boutique hotel in Cassis, France. It welcomes the guest, lays out their stay
details and receipt, shares a warm note from the host, and provides handy
guest information for arrival, wifi, and breakfast.
 
The main goal of this project was to accurately implement a high-fidelity
design using Bootstrap for as much of the layout and styling as possible,
with custom CSS filling in the gaps.
 
## 📋 About the project
 
The layout is split into two main areas: a branded sidebar on the left with
navigation, local weather, and hotel info, and a main content area on the
right containing the confirmation details. On larger screens, the receipt
and welcome cards overlap for a layered, physical look, and the whole page
gracefully stacks into a single column on smaller screens.
 
## 🛠️ Built with
 
- Semantic HTML5
- Bootstrap 5 — grid system, components (cards, buttons, badges), and utility classes
- Custom CSS — for the color palette, typography, and the overlapping card layout
- CSS custom properties (variables) for consistent colors and fonts
- Google Fonts — Fraunces, DM Sans, and DM Mono
## ✨ Features
 
- Fully responsive layout that adapts from mobile to desktop
- Two-column layout with a branded sidebar and main content area
- Overlapping receipt and welcome cards on larger screens
- Booking details with a check-in/check-out summary and cost breakdown
- Guest information cards for arrival, wifi, and breakfast
## 📚 What I learned
 
This project was great practice for combining Bootstrap's utility-first
approach with custom CSS. Some highlights:
 
- Using Bootstrap's grid to build a responsive multi-column layout
- Knowing when to reach for a utility class versus writing custom CSS
- Creating an overlapping card effect with positioning and negative margins
- Managing colors and fonts cleanly with CSS variables
